# 未央的个人博客

采用 Carbon Typst Blog 模板构建，记录个人的学习和成长历程，分享技术文章和生活点滴。

## Carbon Typst Blog 模板介绍

Carbon Typst Blog 是一个基于 Typst 的静态博客生成器，旨在提供一个简洁、高效的博客构建流程。通过使用 Node.js 脚本进行构建，支持多线程加速和预览构建，适合个人博客或小型项目使用。

项目仓库：
<https://github.com/tiger2005/carbon-typst-blog>
